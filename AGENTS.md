# Project Context

- This repository is a personal portfolio website.
- The owner is not a developer. Explain changes in plain language and avoid assuming technical knowledge.
- The owner's expected ongoing tasks are publishing new articles and making occasional minor visual edits.
- The owner will not build or run the website locally. The website is built only after changes are pushed to GitHub.
- Do not require local build or preview steps in owner-facing instructions; use static checks where possible and explain that final deployment validation happens through GitHub.
- Keep the article-publishing workflow simple, documented, and difficult to break.
- Prefer small, maintainable changes over adding tools, dependencies, or architectural complexity.
- Preserve the existing design and content structure unless the owner explicitly asks for a broader redesign.
- When handing off changes, clearly say what changed and what the owner needs to do next, if anything.
